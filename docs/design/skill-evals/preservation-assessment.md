records where each material do/don't of the pre-overhaul skill (frozen under

Removed on purpose: the instruction to run `archboard semantic config` and
`archboard check` before any work (the vocabulary is one file read, and a
write's own answer carries its warnings), and the instruction to use
`archboard help <command>` for syntax (the recipes show the syntax the common
paths need; a refusal names its rule). Both are discovery the context already
answers; the eval classifies them as `discovery` so the comparison shows
whether the candidate stops making them.

Not measured here: the baseline/candidate comparison (TASK-211 AC #6) is a
human-run step; see `evals/README.md`.
