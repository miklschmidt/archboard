# Side ports in Lanes, measured

This note keeps the measurements behind the side-port decision in
[ADR 0096](../adr/0096-track-is-replaced-by-lanes.md). It was written on 2026-11-23 and describes the
corpus as it stood then.

## The corpus

The corpus held 111 Lanes readings of this repository's vault and the web shop's. Each reading was
laid out twice: with every line end on a card's top or bottom face, and with side ports.

| Measure     | Change with side ports |
| ----------- | ---------------------- |
| Bends       | 7% fewer               |
| Page area   | 3% smaller             |
| Line length | 4% shorter             |
| Crossings   | one fewer              |

The two advisors judged the change on paired pictures of the root, Packages, workspace, Painting
and Archboard server readings in both themes, and chose side ports.
