Archboard keeps a model of your architecture next to your code. Your agent writes the model through the CLI. Archboard draws it, checks it against the code, and shows how a change moves it.

## Try it

```bash title="In a repository you want to map"
npm install --global archboard
archboard init
archboard check
```

`init` makes the vault and installs the skills. Then ask your agent to map the repository. [A first map in one session](first-map/) gives the prompts.
