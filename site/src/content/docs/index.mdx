Archboard stores an architecture model in your repository alongside your code. Your coding agent updates the model through the CLI. Archboard renders diagrams from it, checks the model against the codebase, and shows how pull requests change the architecture.

## Try it

```bash title="In a repository you want to map"
npm install --global archboard
archboard init
archboard check
```

`archboard init` creates `.archboard/vault` and installs the agent skills. Next, ask your coding agent to map the repository. See [Map your first repository](first-map/) for example prompts.
