## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The CLI checks mix public package execution, command-contract generation, documentation audits, repository registries, and local HTTP doubles. Convert check-cli-surface, check-command-contract, check-command-workflows, check-install-doc, and check-repos into typed black-box tests.
