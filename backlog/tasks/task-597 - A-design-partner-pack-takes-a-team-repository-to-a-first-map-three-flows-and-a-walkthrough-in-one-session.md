## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A coding session forgets what it learned when it ends, and a team needs a durable first map of its system. Archboard has `install-skill`, model edit and read, flows and walkthroughs, but no path that a design partner can follow from nothing to a first walkthrough (P2 of the market research).
<!-- SECTION:DESCRIPTION:END -->

The docs page /docs/first-map/ is the written path: install and archboard init (which installs the skills), a first map, three flows and a newcomer walkthrough, with the prompts to give the agent. AC 2 and AC 3 need a real design partner repository and their feedback, so they stay open.
