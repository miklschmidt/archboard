## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The first integrated build of the rebuilt UI (commit 15ca4628, viewed live on 2026-09-06) is structurally complete but the user judged it needs a very thorough polishing pass before it reads as the operator canvas reference: density, hierarchy, typography roles, spacing rhythm, control sizing, state presentation and copy are still first-draft. This task is the deep, full-effort pass over every rendered region in both themes, one and two panes and fullscreen, at 1920x1080, measured against docs/design/operator-canvas-shell.md and docs/design/assets/operator-canvas-shell.png, using only the shared shadcn components and Tailwind under the existing strict src/ui policy. It runs after TASK-150.06's browser lane is green so test retargeting and polish do not collide, and every polish change re-runs the affected browser owners.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Header, navigator, pane bar, canvas stage, inspector, notices, dialogs and workbench dock match the reference's composition, density and one-pixel-rule flatness in both themes at 1920x1080, verified by rendered screenshots recorded in the task
- [x] #2 Typography follows the documented roles exactly: Onest for human text at the documented weights, DM Mono only for identifiers, paths, versions and times; no unstyled Excalidraw or browser default text leaks into Archboard chrome
- [x] #3 Every interactive control has a visible focus ring, a 44px-equivalent target or documented exception, an accessible name, and keyboard reachability; Escape, portal stacking and focus return work in every dialog and menu
- [x] #4 Empty, loading, partial, failure and recovery states of navigator, panes, inspector, notices and workbench read as designed states with actionable copy, not placeholders; no red default-destructive text is used for ordinary unavailability
- [x] #5 Smaller desktop windows keep the composition with the canvas flexing and overflowing regions scrolling; nothing clips at 1360px wide
- [x] #6 Strict lint, type-check, build, module tests and the complete serial browser lane pass after the pass; every retargeted browser assertion is recorded with its rationale
